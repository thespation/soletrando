Regras e Instruções do Soletrando

Como Funciona

O Soletrando é um jogo de soletração onde os alunos devem dizer as letras de uma palavra, uma por uma, na ordem exata.

Regras Importantes

  • Ordem Obrigatória: As letras devem ser ditas na ordem exata, do início ao fim.
  • Um Erro Elimina: Um único erro na letra elimina o aluno da rodada.
  • Acentos: Acentos são obrigatórios. Dizer "A" quando a letra é "Ã" conta como erro.
  • Letras Repetidas: Cada letra deve ser dita na sua vez. Se a palavra tem dois "R"s, o aluno deve dizer "R" duas vezes.
  • Hífens: Hífens também são soletrados quando fazem parte da palavra.

Exemplos

AÇÃO = A · Ç · Ã · O

FÉRIAS = F · É · R · I · A · S

CARRO = C · A · R · R · O

BEM-CEDO = B · E · M · - · C · E · D · O

Para o Professor(a)

  • O professor seleciona a série, turma e disciplinas antes de começar.
  • O professor digita cada letra falada pelo aluno.
  • O aluno apenas fala em voz alta - não digita nem clica.
  • Não existe tempo limite para soletrar.
